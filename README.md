# Shumoul Server — Windows releases

Installers and `update.json` for the Windows version of Shumoul Server.

Installed copies check `releases/latest/download/update.json` for new versions.
Each release holds:

- `*-Setup-<version>.exe` — the installer
- `update.json` — version, minimum required version, download URL, SHA-256 and notes

No source code is kept here.
